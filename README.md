# الدرع 🛡️

درع لكل طفل يكبر بالأفعال القوية، ويتشرخ بالأفعال الضعيفة، ويتصلّح بالاعتذار وإصلاح الخطأ.
تطبيق ويب يعمل على الهاتف والكمبيوتر، ويمكن تثبيته على الشاشة الرئيسية واستخدامه دون إنترنت.
لا حسابات ولا خوادم: كل البيانات تبقى في متصفح المستخدم.

## الملفات

| الملف | ما هو |
|---|---|
| `index.html` | التطبيق كله. صفحة «عن الفكرة وطريقة الاستخدام» في الجزء المعلَّم بـ «صفحة المعلومات» داخله |
| `manifest.webmanifest` | تعريف التطبيق للتثبيت: الاسم والألوان والأيقونات |
| `sw.js` | يجعل التطبيق يعمل دون إنترنت |
| `icon-*.png`، `apple-touch-icon.png` | الأيقونات |

## النشر على GitHub Pages

1. ارفع كل الملفات إلى جذر المستودع.
2. من **Settings ← Pages**: اختر **Deploy from a branch**، والفرع `main`، والمجلد `/ (root)`، ثم **Save**.
3. بعد دقيقة أو دقيقتين يظهر الرابط في الصفحة نفسها.

## تعديل نص الدليل

افتح `index.html` وعدّل النص بين السطرين:

```
<!-- ===== صفحة المعلومات: عدّلي النص بين السطرين التاليين ===== -->
<!-- ===== نهاية صفحة المعلومات ===== -->
```

العلامات: `#` عنوان رئيسي، `##` قسم (يظهر زرًا في الفهرس)، `-` نقطة، `1.` ترقيم، `>` اقتباس، `**نص**` غامق.

## عند تحديث الموقع

1. عدّل الملفات وارفعها.
2. **غيّر رقم الإصدار** في أول سطر من `sw.js` (مثلًا `shield-1.0` ← `shield-1.1`)، حتى تصل النسخة الجديدة للمستخدمين الذين ثبّتوا التطبيق.
3. لا تغيّر عنوان الموقع، ولا القيمة `lsKey` داخل `index.html`: البيانات مرتبطة بهما، وتغييرهما يجعل المستخدمين يبدؤون من الصفر.
